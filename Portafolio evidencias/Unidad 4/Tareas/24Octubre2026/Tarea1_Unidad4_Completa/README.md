# Tarea 1 Unidad 4 — Simpson 1/3 Compuesto

## Archivos
- `src/dif_e_Integracion/TrapecioCompuesto.java`
- `src/dif_e_Integracion/SimpsonCompuesto.java`
- `src/dif_e_Integracion/MainTrap.java`

## Compilar
Desde la carpeta raíz del proyecto:

```bash
javac -d out src/dif_e_Integracion/*.java
```

## Ejecutar

```bash
java -cp out dif_e_Integracion.MainTrap
```

La función usada es `f(x) = x²`, con intervalo `[0, 1]` y tolerancia `1e-5`.
